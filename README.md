# ValutaTrade Hub

**ValutaTrade Hub** — консольное приложение для управления валютным портфелем, покупки и продажи валют, а также отслеживания актуальных обменных курсов.

## Описание проекта

Приложение позволяет пользователям:
- регистрироваться и авторизовываться;
- создавать персональные валютные портфели;
- управлять балансами валютных кошельков;
- покупать и продавать валюту;
- просматривать обменные курсы;
- получать общую оценочную стоимость портфеля в базовой валюте.

Курсы валют будут загружаться из внешних API и сохраняться локально в JSON-файлах.

## Хранение данных

Локальные данные приложения хранятся в каталоге `data/`:

- `users.json` — данные пользователей;
- `portfolios.json` — валютные портфели;
- `rates.json` — актуальные курсы валют;
- `exchange_rates.json` — история обновления курсов.


## Кэширование курсов

Для хранения обменных курсов используется локальный кэш с ограниченным временем жизни (TTL). В настройках (Singleton `Settings`) заложен параметр `ttl_seconds`, который в дальнейшем будет использоваться для проверки актуальности файла `rates.json`. Устаревшие курсы обновляются через Parser Service.

## Parser Service

Сервис получения курсов использует внешние API (ExchangeRate-API) через библиотеку `requests`. Полученные данные сохраняются в `rates.json` с меткой времени. Настройки API и ключи доступа хранятся в переменных окружения.

## Разработка

Проект разрабатывается поэтапно с использованием Git. Каждая крупная функциональная часть фиксируется отдельным коммитом.

### Реализованные компоненты

**1. User — модель пользователя**
- Создание пользователя с уникальным идентификатором.
- Проверка имени пользователя и пароля.
- Хеширование пароля SHA-256 с индивидуальной солью.
- Проверка введённого пароля.
- Получение информации о пользователе без раскрытия пароля.
- Сериализация и восстановление данных пользователя.

**2. Wallet — модель валютного кошелька**
- Создание кошелька с указанной валютой и начальным балансом.
- Проверка корректности валюты и баланса.
- Пополнение кошелька.
- Списание средств с проверкой доступного баланса.
- Получение информации о кошельке.

**3. Portfolio — модель валютного портфеля**
- Создание портфеля пользователя.
- Добавление валютных кошельков.
- Проверка уникальности валют.
- Получение кошелька по коду валюты.
- Получение владельца портфеля.
- Получение копии списка кошельков.
- Расчёт общей стоимости портфеля в выбранной базовой валюте.
**4. Бизнес-логика (Usecases)**
Вся основная логика работы с портфелем вынесена в отдельный слой `core/usecases.py`:
*   **`buy_currency`** — покупка валюты. Проверяет достаточность средств на USD-кошельке, списывает доллары и зачисляет купленную валюту. Обрабатывает кастомные исключения (`InsufficientFundsError`, `CurrencyNotFoundError`).
*   **`sell_currency`** — продажа валюты. Проверяет баланс продаваемой валюты, списывает её и зачисляет вырученные USD на кошелек.
*   **`get_rate`** — получение актуального курса валюты из кэша. В случае отсутствия курса или его устаревания (TTL) выбрасывает исключение `StaleRatesError` или запрашивает обновление.

### Проверка качества кода

- Проверка стиля кода с помощью Ruff.
- Проверка основных операций моделей через запуск Python-команд.
- Проверка расчёта стоимости портфеля на тестовых курсах.
